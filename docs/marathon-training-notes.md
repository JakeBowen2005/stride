# Marathon Training Notes — Sub-3:00 Block (Aug 2025 – Feb 2026)

> Result: **2:58:42** on Feb 1, 2026 (6:46/mi avg)
> These notes are derived from Jake's actual Strava data and descriptions.
> The plan generator should reference this file when building marathon-specific plans.

## Training Philosophy That Worked

1. **Two quality sessions per week** — one threshold/tempo, one speed/shorter reps
2. **Weekly long run is non-negotiable** — progressed from 15mi → 21mi over the block
3. **Long runs became race-specific** — not just easy miles, incorporated marathon pace segments
4. **Threshold work was the bread and butter** — 3x2mi and 4x2mi at ~6:20-6:40 were the core workouts
5. **Progressive overload** — same workout structures got faster over time (3x2mi went from 6:38 avg → 5:58 last rep)
6. **Easy days were truly easy** — 9:00-9:40/mi on recovery and easy days
7. **Consistency over heroics** — 50-70 mpw sustained for months, not one massive week

## Long Run Progression Pattern

The long run structure evolved through the block:
1. **Early**: Pure easy long runs (15-18mi @ 8:00-9:00)
2. **Middle**: Tempo finish long runs (easy start, last 6-8mi at MP or faster)
3. **Late**: Complex MP long runs with mixed segments (easy/moderate/MP blocks)
4. **Peak**: Full race simulation (21mi with 12mi at MP)
5. **Taper**: Reduced distance but maintained some quality (15mi with 5 at MP, then 12mi pure easy)

## What Made This Block Work

1. **Called the goal 300 days out** — committed Aug 1 to run sub-3 on Feb 1
2. **Training partner** — Ethan Irwin (accountability, shared long runs, shared race)
3. **Consistency** — 7 runs/week most weeks, rarely missed
4. **Progressive long runs** — didn't just run easy long, made them race-specific
5. **Threshold work** — 3x2mi was the signature workout, done almost weekly with improving times
6. **Trusted the process** — bad days happened (Oct 28, Jan 6) but kept showing up
7. **Smart taper** — dropped volume but kept some intensity (10 easy + 5 at MP)
8. **Mental toughness built through training** — the 19mi and 20mi race-sim runs built confidence

## The #1 Lesson: Mileage & Consistency Win

- Jake initially aimed for 50 mpw but realized he needed MORE to break 3:00
- Peaked at 70 mpw and that's when fitness really clicked
- The consistent 55-65 mpw blocks (Nov-Dec) built the foundation; the 70mi peak week (Jan) sharpened it
- Sub-3 on 25-30 mpw is unrealistic — the plan generator must enforce appropriate volume
- Consistency over months > any single workout. Jake ran 7 days/week for most of this block
- The 300-day commitment (Aug 1 → Feb 1) shows that long-term consistency is the real secret

## Notes for Plan Generator

- **Mileage first, always.** Build to appropriate weekly volume before adding hard workouts
- When building a marathon plan, the 3x2mi threshold repeat should be a staple workout
- Long runs should progressively incorporate more MP work as race approaches
- The "easy/moderate/marathon pace" sandwich structure works well for long runs
- Taper should maintain some quality, not just cut everything
- 55-65 mpw is the sweet spot for this athlete, with a peak around 70
- Recovery long runs (easy pace, no quality) should alternate with race-specific long runs
- The athlete responds well to negative splitting workouts
- Float/jog rest between reps (0.25mi or 1mi) rather than standing rest
- For any ambitious marathon goal, plan for at least 4-5 months of consistent 50+ mpw training
- Don't prescribe workouts until the runner has built a solid mileage base first
